# 🐉 Драконья Поляна

Фиджитал-игра для детей 6–11 лет: ребёнок получает задание, выполняет его в реальной жизни (прогулка, чтение, поиск предметов), взрослый вычисляет математическое выражение — и дракон получает опыт и растёт.

**Технологии:** Node.js, Express, sql.js (SQLite в браузере/на сервере без нативных зависимостей), HTML5, CSS3, Vanilla JS

## Что делает

- 4 дракона по направлениям: математика, русский язык, логика, окружающий мир
- Случайная генерация заданий и математических выражений под каждый тип
- Начисление опыта (XP) и прогрессия уровней (1–5) для каждого дракона
- REST API для получения заданий, проверки ответов и отслеживания прогресса
- Полностью автономный backend — база данных на sql.js, отдельный сервер не нужен

## Архитектура

```
dragon-meadow/
├── server.js              ← точка входа (Express)
├── src/
│   ├── db.js               ← инициализация SQLite + запросы
│   ├── routes.js           ← API-маршруты
│   └── expressions.js      ← генератор математических выражений
└── public/                 ← фронтенд (статика)
```

## API

| Метод | Путь          | Описание                        |
|-------|---------------|----------------------------------|
| GET   | `/dragons`    | Список драконов с уровнями       |
| GET   | `/task/:type` | Случайное задание + выражение    |
| POST  | `/complete`   | Проверка ответа, начисление XP   |
| GET   | `/progress`   | Суммарный прогресс всех драконов |

## Запуск локально

```bash
npm install
npm start
```
Открыть в браузере: `http://localhost:3000`
