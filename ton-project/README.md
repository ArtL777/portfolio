# TON Jetton Transfer Module

Асинхронный Python-модуль для выполнения переводов Jetton-токенов в сети
The Open Network (TON).

Проект демонстрирует работу с TON-блокчейном на уровне контрактов,
формирование payload вручную и взаимодействие с Jetton-стандартом через
низкоуровневые библиотеки.

------------------------------------------------------------------------

## 🚀 О проекте

Модуль реализует:

-   Валидацию TON-адресов\
-   Перевод Jetton-токенов\
-   Добавление текстового комментария в транзакцию\
-   Восстановление кошелька из мнемонической фразы\
-   Управление комиссией и nanoTON

Работа ведётся через Toncenter API (mainnet).

------------------------------------------------------------------------

## 🧠 Архитектура

### Валидация адреса

Используется Address из pytoniq_core с обработкой исключений.

### Перевод Jetton

Логика работы:

1.  Инициализация клиента блокчейна\
2.  Восстановление кошелька через WalletV4R2\
3.  Получение jetton-кошелька через JettonMasterStandard\
4.  Формирование комментария через begin_cell()\
5.  Создание transfer body через JettonWalletStandard\
6.  Отправка транзакции в сеть
